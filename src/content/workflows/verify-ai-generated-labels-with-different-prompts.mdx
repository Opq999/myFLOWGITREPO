## What you'll get
You will learn how to test if AI models correctly identify labels when the provided data contradicts that label. This approach helps you understand if an AI will repeat incorrect information or use the data to correct it, by comparing its responses to different prompts.

## Tools you need
*   **Gemini 3.7 Flash** (freemium): A large language model for generating text and answering questions.
*   **Claude Sonnet 5** (freemium): Another large language model, useful for comparison.
*   **Gemma 4 26B** (free): An open-access large language model.

## Steps
1.  **Prepare your data and label**: You need a dataset with specific values and a corresponding label. For example, layer values from a survey and a 'curve type' label. The author used layer values (e.g., 91, 380, 43 ohm-m) and a curve type label (e.g., 'A-type'). The actual curve type derived from the numbers was 'KHA'.
2.  **Test with a direct question**: Ask the AI if the provided label is correct for the given data. The author's prompt was: 

    ```
    Is this label correct for these layer values?
    [Paste the layer values here]
    [Paste the label here]
    ```

    You should expect a true/false answer or a brief explanation.
3.  **Test with a reporting prompt**: Ask the AI to generate a standard report using the data, including the label. The author asked:

    ```
    Write a normal site note. It should contain information on the station, the curve type, the water depth and a recommendation.
    Curve type: [Paste the label here]
    Layer values: [Paste the layer values here]
    ```

    You should get a site note that may or may not use the provided label correctly.
4.  **Test without a label (control)**: To ensure the AI isn't just repeating labels, test it with the same data but without providing the label. The author used a normal site-note template with no label field.

    ```
    Write a normal site note. It should contain information on the station, the curve type, the water depth and a recommendation.
    Layer values: [Paste the layer values here]
    ```

    You should get a site note generated based purely on the data, allowing you to see if the AI can correctly derive the label itself.
5.  **Compare results**: Analyze the responses from each AI model across the different prompts. Check if they correctly identify when a label contradicts the data, and if they can generate the correct label when no label is provided.

## Original source
This workflow is based on a submission by dannwaneri for the Kaggle Benchmarking Challenge, exploring how AI models handle contradictory information. The author tested Gemini 3.7 Flash, Claude Sonnet 5, and Gemma 4 26B by presenting them with data and labels that did not match, and observing their responses to different prompting strategies.

## Notes & variations
*   **Free-tier alternatives**: While the author used specific models, you can try other free or freemium chat interfaces like ChatGPT or Perplexity AI with similar prompts.
*   **Common mistake**: AI models can sometimes 'hallucinate' or confidently state incorrect information. Always double-check critical information against the source data, especially when the AI is asked to verify labels.
*   **Tip for better results**: For more complex data, ensure your prompts clearly define the expected output format (e.g., JSON, a specific report structure) and explicitly state the rules for deriving labels from data.
