## What this is, in plain English
HyperFrames is an open-source framework that lets you create MP4 videos using HTML, CSS, and various media elements. Think of it as a specialized tool that takes web page descriptions and turns them into video files.

This workflow is specifically "Built for agents," meaning it's designed to be used by AI coding agents, not directly by a human in a simple chat interface. An AI coding agent is a program that can write, debug, and execute code on its own, often interacting with other developer tools.

Because it relies on AI coding agents and command-line tools, this workflow is advanced. It requires setting up a development environment, installing specific software, and understanding how to interact with AI agents programmatically. There isn't a simple copy-paste recipe for beginners, as the exact steps depend heavily on your chosen AI agent and development setup.

HyperFrames uses a concept called "skills" to teach AI agents how to plan, write valid HTML, add animations and media, and finally render a video. These skills guide the agent through the entire video production process.

## What you can use it for
*   **Automate video creation**: Generate product introductions, animated compositions, or short promotional videos from simple text descriptions.
*   **Programmatic video generation**: Create many videos quickly by describing them using HTML/CSS, which is useful for dynamic content or personalized video campaigns.
*   **AI-driven content creation**: Let an AI agent handle the technical details of video production, from planning the layout to rendering the final MP4 file.
*   **Experiment with AI coding agents**: Learn how to integrate specialized tools like HyperFrames into an AI agent's workflow, expanding the agent's capabilities.

## How it actually works
This workflow involves setting up a development environment and then instructing an AI coding agent to use HyperFrames. The exact steps for setting up an AI agent can vary significantly.

1.  **Set up Node.js and npm/npx**: You need to install Node.js on your computer. This will automatically include npm (Node Package Manager) and npx, which are essential for running HyperFrames commands. You can download it from the official Node.js website.

2.  **Install an AI Coding Agent**: The author mentions compatibility with Claude Code, Cursor, Gemini CLI, and Codex. You will need to choose and set up one of these agents. This often involves installing specific software, configuring API keys, and potentially setting up a development environment like a code editor or a terminal. The author doesn't share specific setup instructions for these agents.

3.  **Install HyperFrames skills**: Once your AI coding agent is set up and you have Node.js installed, you will use the `npx` command to install the HyperFrames "skills." These skills teach your agent how to use HyperFrames.

    ```bash
    # macOS or Linux
    npx skills add heygen-com/hyperframes --full-depth
    ```

    ```powershell
    # Windows (PowerShell)
    npx skills add heygen-com/hyperframes --full-depth
    ```

    The author notes that if you are running this non-interactively or with an agent, `npx hyperframes skills update` installs the core set of skills directly.

4.  **Prompt your AI agent**: After the skills are installed, you will interact with your chosen AI coding agent, providing it with a prompt describing the video you want to create. The agent will then use the HyperFrames skills to plan, write the necessary HTML and CSS, add media, and render the final MP4 video.

    The author suggests a prompt like this:

    ```
    Using /hyperframes, create a 10-second product intro with a fade-in title, a background video, and subtle background music.
    ```

    The specific way you provide this prompt to your agent (e.g., through a chat interface, a command-line input, or a code file) will depend on the agent you are using. The agent will then execute the HyperFrames workflow to generate the video.
