## What this is, in plain English

This workflow describes how to use a decision model called Jev, accessed through a tool called Composio, to moderate live chat on platforms like Discord and Twitch. Unlike typical AI models that generate text, Jev is designed to make quick decisions based on probabilities. For chat moderation, this means it can quickly tell you if a message is likely to be harmful, allowing for faster removal or review.

The core idea is to use Jev's ability to provide a probability score for specific questions about a chat message. For example, you can ask Jev, "Is this a hostile comment at a person?" and it will return a number between 0 and 1. This score can then be used to automatically decide whether to delete the message, send it for human review, or leave it be. This approach is faster and cheaper than using a large language model (LLM) for the same task.

7.  **Connect Jev for Twitch moderation**: Similar to Discord, send Twitch chat messages to Jev via Composio for evaluation.
8.  **Implement Twitch moderation actions**: Use the Twitch API to delete messages or take other actions based on Jev's decision.

## Notes & variations

*   **Do you even need this?**: If your chat moderation needs are very simple (e.g., just blocking specific keywords), you might be able to achieve this with built-in moderation tools on Discord or Twitch, or simpler bots, without needing an AI model.
*   **Free-tier limits**: Composio's free tier may have limits on usage. Check their pricing page for details. Jev itself is free, but running it might incur costs depending on how it's hosted or accessed.
*   **Common pitfall**: Relying solely on AI for moderation can be risky. AI models can sometimes make mistakes or miss nuanced harmful content. It's recommended to keep human moderators involved, especially for sensitive communities or high-stakes situations.
