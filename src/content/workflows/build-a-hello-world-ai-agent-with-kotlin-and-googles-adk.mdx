## What this is, in plain English
The Agent Development Kit (ADK) is a framework from Google that helps developers build AI agents using code. An AI agent is a program that can understand instructions, make decisions, and use tools to complete tasks, much like a smart assistant. This specific workflow uses Kotlin, a modern programming language, to create a simple "Hello World" agent.

This approach is considered advanced because it requires you to write and run code, set up a development environment, and understand programming concepts. It's not a simple copy-paste task for a beginner, as the exact instructions involve navigating a code repository and running commands in a terminal.

The ADK gives developers fine-grained control over how their agents behave, connect to AI models like Gemini, and use external tools. This allows for complex, custom AI solutions that can be debugged and deployed anywhere.

## What you can use it for
*   **Automate tasks**: Create agents that can perform repetitive actions, like processing data or sending notifications.
*   **Build smart assistants**: Develop custom AI assistants that can understand user requests and interact with specific services.
*   **Integrate AI with existing systems**: Connect AI capabilities directly into your current applications and software.
*   **Develop complex AI workflows**: Design agents that can orchestrate multiple steps and tools to solve more intricate problems.
*   **Experiment with agent behavior**: Gain deep control over how an AI agent makes decisions and uses its tools, allowing for advanced customization.

## How it actually works
1.  **Install Java 25**: You need Java 25 to run this project. SDKMAN! is a convenient tool for installing and managing Java versions on macOS and Linux. Windows users should use Windows Subsystem for Linux (WSL).

    ```bash
    # macOS or Linux
    sdk list java
    sdk install java <your_preferred_java_25_distribution> # e.g., sdk install java 25.0.2-tem
    java --version
    ```

    ```bash
    # Windows (WSL)
    # Run these steps inside Windows Subsystem for Linux (WSL) after installing WSL.
    # Follow the macOS or Linux commands above within your WSL terminal.
    ```

2.  **Get a Gemini Developer API key**: Go to Google AI Studio (ai.google.dev) and create an API key for the Gemini model. This key allows your agent to connect to Google's AI services.

3.  **Clone the sample project**: Download the author's sample "Hello World" ADK project from GitHub to your computer.

    ```bash
    git clone https://github.com/xbill9/adk-hello-world-kotlin.git
    cd adk-hello-world-kotlin
    ```

4.  **Configure your environment**: Copy the example environment file and add your Gemini API key to it. This file tells the agent how to connect to the Gemini model.

    ```bash
    cp .env.example .env
    # Open the .env file in a text editor and replace "YOUR_API_KEY" with your actual Gemini API key.
    source ./set_env.sh
    ```

5.  **Run the MCP server**: In one terminal window, start the local server that provides the `greet` tool. This server makes the tool available for your AI agent to use.

    ```bash
    ./gradlew :server:run
    ```

6.  **Run the ADK agent**: In a *separate* terminal window, start the AI agent. This agent will use the Gemini model and the local `greet` tool.

    ```bash
    ./gradlew :agent:run
    ```

7.  **Interact with the agent**: Once both the server and agent are running, you can interact with the agent through its `ReplRunner` (Read-Eval-Print Loop Runner) in the agent's terminal window. The agent should be able to use the `greet` tool you set up.

## Notes & variations
*   **Do you even need this?**: For simpler AI tasks that don't require custom tools or deep integration, you might find consumer-facing AI chat applications (like claude.ai or gemini.google.com) or no-code AI tools more suitable. This ADK workflow is for developers who need fine-grained control and want to build custom, integrated AI solutions.
*   **Free-tier limits**: While the ADK itself is free, using the Gemini API will incur costs beyond its free tier. Always monitor your API usage and set budget alerts to avoid unexpected charges.
*   **Common pitfall**: A common issue is incorrect Java version setup. Ensure you have Java 25 installed and active. If you encounter errors, verify your `java --version` output matches the requirement.
*   **Tip for better results**: Familiarize yourself with Kotlin basics and the ADK documentation on adk.dev before diving into complex agent designs. Understanding the core concepts will make debugging and extending the agent much easier.
