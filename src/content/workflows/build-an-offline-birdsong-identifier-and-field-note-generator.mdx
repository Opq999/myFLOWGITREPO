## What this is, in plain English

This project describes how to build a "cyberdeck," which is essentially a portable, customizable computer designed for specific tasks, often with a retro or rugged aesthetic. The "B.L.O.O.M." cyberdeck is built for naturalists, allowing them to work completely offline in the field.

It combines hardware like an Arduino UNO Q with AI models for identifying birdsong and generating text-based field notes. The system captures audio and images, processes them locally using AI, and stores the information in a database. When you choose to reconnect, it can sync this data to a community website.

This project is advanced because it involves wiring custom hardware, running AI models directly on a small device (local AI), and connecting various software services. The exact steps for wiring, setting up the Arduino, and configuring the AI models are detailed in external resources, making a simple copy-paste recipe here impossible.

## What you can use it for

*   **Identify birdsong in real-time**: Use the device in a natural setting to automatically recognize bird calls and identify the species.
*   **Capture field notes offline**: Record observations, sketches, and AI-generated notes without needing an internet connection.
*   **Generate vintage-style field sketches**: Create artistic representations of your observations that mimic traditional naturalist drawings.
*   **Build a privacy-focused device**: Keep all your data local and only sync it to the cloud when you decide, ensuring your observations remain private.
*   **Learn about local AI**: Experiment with running AI models directly on small, embedded hardware like the Arduino UNO Q.
*   **Create a portable, hackable computer**: Assemble a unique, functional computer rig for specific outdoor or research tasks.

## Tools you need

*   **Arduino UNO Q** (paid): A small, programmable computer board that acts as the brain for the cyberdeck, running the AI models and managing peripherals.
*   **Edge Impulse** (freemium): A platform for developing machine learning models for edge devices, used here to train a birdsong classifier.
*   **Cloudinary** (freemium): A cloud-based service for image and video management, used here to generate stylized field sketches.
*   **Gemma LLM** (freemium): A small language model from Google, used here to generate AI-powered field notes.
*   **SQLite** (free): A lightweight database that stores all your captured field notes and data directly on the device.
*   **GitHub** (freemium): A platform for hosting and collaborating on code, used here to store project code and potentially sync data via pull requests.
*   **Netlify Function** (freemium): A service that allows you to run serverless code, used here to handle the process of syncing data to GitHub.
*   **Octokit** (free): A library that helps you interact with the GitHub API, used to automate the creation of pull requests for data syncing.
*   **Astro** (free): A modern web framework used to build fast, content-focused websites, likely used for the community site that receives synced data.

## How it actually works

1.  **Gather Hardware**: Collect the listed components: Arduino UNO Q, USB hub, microphone, camera, HDMI screen, power bank, Bluetooth keyboard, and an enclosure (like a vintage makeup case).
2.  **Assemble the Cyberdeck**: Wire all the hardware components together using the USB hub and connect them to the Arduino UNO Q. The Arduino will run in a "Chromium kiosk" mode to display information.
3.  **Set up Local AI Models**: Use Arduino App Lab bricks to load and run a local Gemma LLM for note generation and an audio classifier trained with Edge Impulse for birdsong identification on the Arduino UNO Q.
4.  **Train the Birdsong Model**: If needed, retrain the Edge Impulse birdsong model with your own balanced data to improve its accuracy.
5.  **Capture Data in the Field**: Use the microphone to record birdsong and the camera to capture images. The keyboard and mouse allow you to add manual notes and sketches.
6.  **Generate Field Notes and Sketches**: The Gemma LLM generates AI-powered notes based on your observations, and Cloudinary's image generation API creates stylized sketches using reference images.
7.  **Store Data Locally**: All captured data, including audio, images, AI notes, and sketches, is stored in an SQLite database on the device.
8.  **Sync Data to Cloud (Optional)**: When you have an internet connection, a Netlify Function, using Octokit, can automatically open a pull request on GitHub to sync your SQLite entries.
9.  **Update Community Site**: The synced data can trigger an Astro rebuild to update a live community website.

The full details for wiring and enclosure are available on Hackster. The core cloud-side interaction involves a POST request to Cloudinary for image generation.

## Notes & variations

*   **Do you even need this?**: This is a highly specialized project for enthusiasts interested in custom hardware, offline AI, and a unique aesthetic. For simpler birdsong identification, a smartphone app might suffice.
*   **Free-tier limits**: Edge Impulse and Cloudinary have usage limits on their free tiers, which might restrict the number of model trainings or image generations you can perform. Gemma LLM's local performance depends heavily on the Arduino UNO Q's capabilities.
*   **Common pitfall**: Ensuring all hardware components are correctly wired and powered is crucial. The Arduino UNO Q needs sufficient power, especially when running AI models. Also, properly training the Edge Impulse model with diverse and clear audio samples is key to accurate birdsong identification.
