## What you'll get
You'll get a structured, easy-to-read study guide on any topic you choose, generated by an AI. This approach works by using a pre-defined format that helps the AI organize information in a way that's easier to learn from, controlling the depth of information with your own wording.

## Tools you need
*   **Claude Code** (paid): A code editor with AI features to help you write and run code.
*   **Cursor** (freemium): A code editor that integrates AI to assist with programming tasks.
*   **Codex** (paid): An AI pair programmer that suggests code and entire functions.
*   **Opencode** (freemium): An AI coding assistant that helps you write code faster.
*   **An LLM** (free / freemium / paid): A large language model, like those found in chat applications or code editors, that can understand and generate text.

## Steps
1.  **Access the Philosopher's Skill**: The author mentions this skill works wherever you use an LLM. For a simple approach, you can use a chat app that has browsing capabilities. Paste the following link into your chat app and ask it to follow it: `https://frypan05.github.io/philosopher-OKF/philosopher.md`.
    You should see the chat app acknowledge the link and prepare to follow its instructions.
2.  **Request your study guide**: After the chat app has processed the link, tell it what topic you want a study guide on. You can control the depth of the information by using specific words. For example:
    *   For a short guide: `quick`
    *   For a standard guide: `make a page about [your topic here]`
    *   For a long, in-depth guide: `in depth` or `teach me about [your topic here]`

    For example, to get a standard guide on 'MCP and ACP':
    ```
    make a page about MCP and ACP
    ```
    You should get a study guide on your chosen topic, formatted for easy reading.

The skill is built around the Open Knowledge Format (OKF) to ensure control over information depth and efficient operation.

## Notes & variations
*   **Free tier alternative**: If your preferred chat app doesn't have browsing, you might be able to copy the prompt directly from the `philosopher.md` file (link provided in step 1) and paste it into a model that accepts raw prompts. You will need to manually add your topic to the prompt.
*   **Common mistake**: Asking for a topic without specifying the desired depth (e.g., "quick", "in depth") might result in a guide that is not as detailed or concise as you need.
*   **Tip for better results**: Experiment with different depth requests like "teach me everything about X" or "give me a beginner's overview of Y" to see how the AI adjusts the output.
