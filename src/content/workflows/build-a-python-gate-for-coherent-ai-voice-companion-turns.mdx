## What you'll get
You will create a Python script that acts as a gatekeeper for your AI voice companion. This gate ensures that only complete and coherent sentences are sent to the AI model, preventing issues like sending half-finished thoughts or getting duplicate responses. This approach works by managing the flow of speech segments and AI responses, making the interaction feel more natural and reliable.

## Tools you need
*   **Python** (free): A programming language used to write the script.
*   **OpenAI** (paid): A service that provides AI models to generate responses. You will need an API key and will be charged for usage.
*   **Tencent RTC** (paid): A real-time communication service that handles voice input and output. This workflow assumes you are using it to capture voice and play back AI responses.

## Notes & variations
*   **Free-tier alternative**: While OpenAI and Tencent RTC are paid, you could explore free or lower-cost LLM APIs and real-time communication services if available, though they might have limitations. For local testing without API calls, you could mock the AI responses.
*   **Common mistake**: A common pitfall is not properly handling the `final` flag on transcript segments. Ensure your logic only commits to sending a message to the AI when `final` is true and after a quiet period, to avoid sending incomplete sentences.
*   **Tip for better results**: Clearly define and implement the state transitions described in the article (LISTENING, SETTLING, THINKING, etc.). This structured approach is key to managing the complexity of real-time voice interactions and ensuring the AI receives well-formed inputs.
