## What this is, in plain English
Laya-Guard is a safety tool that runs on your computer to check commands generated by AI coding agents before they are executed. Think of it as a local security guard for your AI, making sure it doesn't accidentally run dangerous or unwanted instructions on your system. It helps prevent issues like deleting important files or exposing sensitive information, all without sending your commands to external, paid AI services.

This workflow is considered advanced because it involves installing and integrating a tool within a developer environment, typically requiring comfort with the command line and understanding of how coding agents operate. The exact steps for integrating Laya-Guard with different coding agents are found within its official repository and can vary, meaning there isn't a single copy-paste recipe for every setup.

The core of Laya-Guard is a small, local AI model (around 322 megabytes) that makes quick decisions (about 85-90 milliseconds on a computer's main processor, or CPU). This local processing means you don't need an internet connection for every check, and you avoid costs associated with paid AI APIs.

## What you can use it for
*   **Prevent dangerous commands**: Stop AI coding agents from executing harmful shell commands like deleting system files.
*   **Guard against malicious actions**: Add an extra layer of security to your automated coding workflows.
*   **Review agent-generated commands**: Get a human review prompt for suspicious commands before they run.
*   **Enhance security for automated tasks**: Ensure that AI tools working on your system adhere to safety policies.

## Tools you need
*   **Laya-Guard** (free): A local AI guardrail that checks shell commands from coding agents.
*   **Claude Code** (paid): An AI coding agent that can generate and execute code.
*   **Cursor** (freemium): An AI-powered code editor that can integrate with coding agents.
*   **Gemini CLI** (free): A command-line interface for interacting with the Gemini API, which can be used by coding agents.
*   **Copilot CLI** (paid): A command-line interface that brings GitHub Copilot's AI assistance to your terminal.

## How it actually works
Laya-Guard works by intercepting the shell commands that your coding agent tries to run. It first applies a set of predefined rules, called regex policies (regular expressions), to quickly catch known dangerous patterns, such as commands that could delete files (`rm -rf /`) or download and execute unknown scripts (`curl ... | sh`). It also looks for attempts to access secrets or bypass security.

Simple, safe commands like `ls` (list files), `git status` (check code changes), or `npm test` (run software tests) are allowed to pass without further checks, but only if they don't involve complex operations like piping data between commands, chaining multiple commands, redirecting output, or using sensitive file paths.

Any command that isn't caught by the regex policies or deemed simple and safe is then sent to the Laya AI model, which runs locally on your computer's CPU. This model quickly decides whether to "allow," "review" (ask for human approval), or "block" the command. The specific steps for integrating Laya-Guard with your chosen coding agent (like Claude Code or Cursor) involve setting up "hooks" that direct the agent's commands through Laya-Guard. You will need to explore the official Laya-Guard GitHub repository for detailed, up-to-date instructions on how to configure these integrations.

To get started, you would typically install Laya-Guard using Python's package installer:

```
# For macOS, Linux, or Windows
pip install laya-guardrail
```

After installation, you would follow the instructions in the Laya-Guard repository to configure its policies and integrate it with your specific coding agent.

## Notes & variations
*   **Do you even need this?**: For simple, manual coding tasks or when you thoroughly review every command your AI generates, a dedicated guardrail like Laya-Guard might be overkill. It is most beneficial when you are using automated coding agents that frequently execute shell commands and you want an extra layer of security without constant manual oversight or reliance on external APIs.
*   **Free-tier limits**: Laya-Guard itself is open-source and free to use. However, many advanced coding agents it integrates with, such as Claude Code or GitHub Copilot, require paid subscriptions or API access, which would be a separate cost. The Gemini CLI, which uses the Gemini API, does offer a free tier.
*   **Common pitfall**: The Laya AI model was primarily tuned using Korean language data. This means that if your coding agent generates natural-language prompts or commands in English, Laya-Guard might be more prone to "overblocking" (blocking commands that are actually safe) compared to models trained specifically on English. Always review blocked commands to understand why they were flagged. Also, be aware that if the Laya-Guard server (the local process running the model) is down, its hooks are designed to "fail open," meaning commands might execute without being checked, which could pose a security risk.
