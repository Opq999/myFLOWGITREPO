## What you'll get
You will get a complete, three-page supply chain control tower application built using ToolJet. This app helps planners track open exceptions, monitor supplier performance trends, and identify inventory components at risk of stocking out. This approach uses an AI agent within ToolJet to generate the entire application from a single prompt, ensuring that the data, queries, and user interface are integrated from the start.

## Tools you need
*   **ToolJet** (free): An open-source low-code platform used to build the control tower application. It can be self-hosted.
*   **PostgreSQL** (free): An open-source database used to store the supply chain data for the application.

    *   *What to do*: Search online for "ToolJet MCP repository" or "ToolJet GitHub" to find the official setup guide. Follow the instructions to install ToolJet on your server or local machine. This typically involves cloning a repository and running setup commands.
    *   *What you should see*: A running ToolJet instance, accessible in your web browser, ready for use.
2.  **Prepare your PostgreSQL database**: The application expects an existing PostgreSQL database with specific tables (e.g., `supply_chain_exceptions`). The author doesn't provide the exact schema or data, so you'll need to set up a basic PostgreSQL database and create the necessary tables.
    *   *What to do*: Install PostgreSQL (if you don't have it). Create a new database and connect it to ToolJet as a datasource. You will need to create tables that match the data the control tower will manage (e.g., `supply_chain_exceptions` for exceptions, `suppliers` for scorecards, `inventory` for stock levels). The author doesn't share the exact table schemas; a starting point would be tables with columns like `id`, `reason`, `severity`, `owner`, `due_date`, `status` for exceptions; `supplier_name`, `performance_score`, `trend` for suppliers; `component_name`, `current_stock`, `forecast_demand`, `next_inbound_date` for inventory.
    *   *What you should see*: Your PostgreSQL database connected as a datasource within ToolJet, ready to be used by the application.
3.  **Generate the application with the prompt**: Use the consolidated prompt provided by the author to generate the three-page control tower application.
