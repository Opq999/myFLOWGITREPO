## What you'll get

You will learn how to set up a process to automatically verify information found by AI against official records. This approach helps ensure the accuracy of your genealogy research by using AI to find potential matches and then confirming them with primary sources.

## Tools you need

*   **Playwright** (free): A tool for automating web browser actions, useful for navigating and extracting data from websites.
*   **Chrome** (free): A web browser that will be controlled by Playwright to visit websites and access records.

## Steps

1.  **Set up Playwright**: Install Playwright and its browser binaries. The exact command may vary slightly depending on your operating system, but it typically involves running an npm command.

    ```bash
    # macOS or Linux
    npm init playwright@latest
    ```

    ```powershell
    # Windows (PowerShell)
    npm init playwright@latest
    ```

    You should see messages indicating that Playwright is being installed and browsers are being downloaded.

2.  **Create a Python script for automation**: The author mentions using a Python project with Playwright. You will need to create a Python file (e.g., `genealogy_verifier.py`) to write your automation script.

3.  **Write the script to browse genealogy sites**: The script should instruct Playwright to open a web browser and navigate to specific genealogy websites. The author suggests creating a 'skill' for each site.

    The author does not provide the exact Python code for this step. A starting point would involve importing Playwright and launching a browser instance:

    ```python
    from playwright.sync_api import sync_playwright

    with sync_playwright() as p:
        browser = p.chromium.launch()
        page = browser.new_page()
        page.goto("https://www.example-genealogy-site.com") # Replace with actual site
        # Add steps here to log in if necessary and search for records
        browser.close()
    ```

    You should see the browser window open and navigate to the specified website.

4.  **Implement data extraction and verification**: Within your script, after navigating to a site and finding a potential record, you will need to extract the relevant information. Then, you'll need to write logic to search for this information in official archives or civil records.

    The author's process involves: mining data from genealogy sites (assigning QUAY 2), checking if the data exists in an official record (civil or parish), and if so, assigning it QUAY 3. If not, discard the data.

## Notes & variations

*   **Free-tier alternative**: While Playwright and Chrome are free, the core challenge is the scripting. If you are not comfortable with Python, you might explore no-code automation tools, though they may have limitations.
*   **Common pitfall**: Websites frequently change their structure. If a site's layout is updated, your Playwright script might break, requiring you to update the selectors used to find information.
*   **Tip for better results**: Start by automating the simplest, most accessible genealogy sites first. Once you have a working script for those, gradually add support for more complex or protected sites, like those requiring logins or advanced bot protection.
