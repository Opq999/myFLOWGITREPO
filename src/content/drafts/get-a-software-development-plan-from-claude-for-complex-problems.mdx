## What you'll get
You will receive a detailed, multi-phase development plan generated by an AI for a complex software problem. This approach helps break down daunting technical challenges into manageable steps, providing a roadmap for further work.

## Tools you need
*   **Claude** (freemium): An AI assistant used to analyze the problem and create the development plan.

## Steps
1.  **Understand the problem context**: The author wanted to create a new macOS driver and companion app for an old Drobo 5D RAID array because the original software would stop working on future macOS versions. The goal was to keep using the device. For your own project, clearly define the technical problem you want the AI to help plan.
2.  **Open Claude**: Go to the Claude website (https://claude.ai).
    *   You should see the chat interface ready for your input.
3.  **Provide context and task to Claude**: The author gave Claude a detailed description of the problem and the goal. They also mentioned providing specific files (drivers, software binaries, release notes) from a local folder. When using the standard Claude chat interface, it cannot access local files. If your problem relies on specific files, you would need to manually copy-paste relevant text from those files into your prompt, or use a Claude API with file upload capabilities if available and supported by the model. For this recipe, paste the author's prompt as-is, but be aware that Claude will not have access to the mentioned local files unless you manually provide their content.

    ```
    The company Drobo has gone out of business (see https://petapixel.com/2023/06/06/drobo-is-officially-done-as-the-company-moves-into-liquidation/) . I own a Drobo 5D which is connected to my mac using USB 3 (the Thunderbolt 2 port will not work on newer mac models) – this still work on my 2017 iMac running macOS Ventura (13). Both the Drobo itself and the Drobo Dashboard software work. On newer macOS version, the Drobo Dashboard software is not compatible anymore and the Drobo can only be mounted as an external drive. For ecology s sake, I have the objective of using this device for as long as possible but do not want to be locked out of macOS (or mac hardware) upgrades. Your task today is to analyse the current Drobo 5D firmware as well as the Drobo Dashboard software, and try to understand WHY it will not work with newer macOS versions, WHAT might prevent the hardware to work on newer mac hardware, and come up with a solution on how to fix this. Everything is on the table: from simple fix to a complete re-write of the driver and Drobo Dashboard for modern mac/macOS. NOTE: I have provided you with some previous (up to the latest) version of the Drobo drivers and Drobo Dashboard inside the /Users/fetzu/Dev/ReDrobo/ZZ_BUFFER folder. Feel free to use these as you see fit, but try avoid installing them on this mac (I don t think you can).
    ```

    *   You should see Claude begin to process the prompt and generate a response. The author notes they were initially on "Fable 5 on High" and then switched to "Opus 5 on Max" after being flagged. This suggests the task might require a more powerful model.
4.  **Review the generated plan**: Claude will provide a multi-phase plan. The author's Claude generated a 5-phase plan, starting with "Protect the data first," then "Validate the protocol," and "Decode the record payloads."
    *   You should receive a structured plan outlining steps to address the complex problem you described.

## Notes & variations
*   **Free-tier limits**: The author used advanced Claude models ("Fable 5 on High," then "Opus 5 on Max"). The free tier of Claude (claude.ai) might have limitations on prompt length or the specific models available. If your prompt is very long or complex, you might need to shorten it or consider a paid tier for access to more powerful models.
*   **Common mistake**: Expecting Claude to *solve* the problem directly. Claude is excellent at *analyzing* and *planning*, but implementing a complex technical solution like a macOS driver requires human expertise and coding. The plan is a roadmap, not the solution itself.
*   **Tip for better results**: Be as specific as possible in your prompt, providing all relevant context, constraints, and objectives. If you have documentation or code snippets, try to summarize or include key parts in your prompt (within length limits) to give the AI more information to work with. For problems involving local files, you might need to manually extract key information from those files to include in your prompt, as web-based AI tools cannot access your local file system.
