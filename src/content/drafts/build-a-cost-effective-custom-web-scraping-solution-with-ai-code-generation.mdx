## What this is, in plain English
This entry describes how to build your own web scraping system from scratch, rather than relying on expensive, ready-made services. Web scraping is the automatic collection of information from websites. The author found that using managed scraping services became very costly for their project, reaching thousands of dollars per month.

To cut costs, they switched to a custom solution. This involves using an AI coding assistant (Claude Code) to help write the necessary code, combined with virtual machines (VMs) and residential proxies. A virtual machine is like a remote computer you can control, and residential proxies are internet addresses that make your scraping requests look like they come from real homes, helping you avoid being blocked.

This method gives you complete control over your data collection process and can drastically reduce expenses. However, it is an advanced approach because it requires setting up servers, managing network connections, and writing code, which is beyond simple copy-paste steps for a beginner.

## What you can use it for
*   **Scrape large amounts of data**: Collect information from many websites without hitting limits or getting blocked.
*   **Reduce scraping costs**: Significantly cut down monthly expenses compared to premium managed services, especially for high-volume tasks.
*   **Gain full control**: Customize every part of your scraping process, from how data is collected to how it's stored.
*   **Bypass anti-scraping measures**: Use residential proxies to make your scraping requests look like they come from real users, avoiding detection.

## Tools you need
*   **Claude Code** (paid): An AI coding assistant or API that helps generate and manage code for complex tasks.
*   **Freestyle** (paid): A residential proxy provider that offers IP addresses from real homes, making web requests appear more legitimate. (The author mentions this as an example; you can use any residential proxy provider).
*   **Evomi** (paid): A virtual machine (VM) provider that offers Linux servers for running your custom scraping code. (The author mentions this as an example; you can use any VM provider).

## How it actually works
This workflow cannot be reduced to simple copy-paste steps because it involves setting up and managing technical infrastructure and writing custom code. The exact instructions will vary based on your chosen providers and specific scraping needs. Here is the general path:

1.  **Choose your providers**: Select a residential proxy provider (like Freestyle) and a virtual machine (VM) provider (like Evomi) that offers full Linux VMs. You will need to sign up for accounts with these services.
2.  **Set up your VM**: Create a virtual machine instance with your chosen provider. This involves selecting an operating system (usually Linux) and server specifications. You will then need to install necessary software, such as Python and a web scraping library (e.g., Playwright or Scrapy), on your VM.
3.  **Integrate proxies**: Configure your web scraping code to route all requests through the residential proxies. This typically involves setting proxy server addresses, usernames, and passwords within your script.
4.  **Develop scraping logic with AI**: Use Claude Code (or a similar AI coding tool) to help write the actual web scraping script. The author doesn't share their exact prompt; a starting point could be:

    ```
    Write a Python script using Playwright to scrape product names and prices from an e-commerce website. The script should use a proxy server at [proxy_address]:[proxy_port] with username [proxy_username] and password [proxy_password].
    ```

    You will need to provide the AI with details about the website you want to scrape and the data you want to extract.
5.  **Deploy and run**: Upload your completed scraping script to your VM. You can then set it up to run manually, automatically on a schedule, or in response to specific events.
6.  **Monitor and maintain**: Regularly check your scraper's performance. Websites often change their structure, which can break your scraper, and proxy providers can have outages. Be prepared to update your code and troubleshoot issues as they arise.

## Words you'll see, explained
*   **Web scraping**: The automatic process of collecting data from websites.
*   **Residential proxy**: An internet address (IP address) that belongs to a real home internet connection, used to make web requests appear as if they come from a regular user.
*   **Virtual Machine (VM)**: A virtual computer that runs on a physical server, allowing you to run your own operating system and software remotely.
*   **Stack**: The combination of technologies (software, servers, networks) used to build and run an application.

## Notes & variations
*   **Do you even need this?**: For small, one-off scraping tasks, simpler tools or even manual copy-pasting might be enough. Only consider this advanced setup if you need to scrape large amounts of data regularly and want to significantly reduce costs compared to managed services.
*   **Free-tier limits**: Claude Code (the API/developer product) does not offer a free tier; it is a paid service. Residential proxy and VM providers typically offer trials or pay-as-you-go models, but a truly free tier for significant usage is rare.
*   **Common pitfall**: Managing proxies and VMs requires ongoing technical skill. Websites often change their structure, which can break your scraper, and proxy providers can have outages. Be prepared for continuous maintenance and troubleshooting.
*   **Alternative tools**: For simpler scraping, consider browser extensions or no-code tools like Octoparse or Apify (which often have freemium tiers). For coding, Python libraries like Beautiful Soup or Scrapy are popular and can be used instead of or alongside AI code generation.
