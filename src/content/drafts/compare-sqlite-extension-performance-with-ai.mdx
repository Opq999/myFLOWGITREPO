## What this is, in plain English
This workflow demonstrates how an AI chatbot, like Claude, can be used as a powerful research assistant for complex programming tasks. Specifically, it shows how to compare different ways to build a custom function for SQLite, which is a small, fast database often used in mobile apps and embedded systems.

The author used AI to explore the differences between creating a `parse_number()` function (which converts text like "$1,234.56" into a number) using two different programming languages: C and Rust. The goal was to compare their performance (how fast they run) and the complexity and size of the resulting compiled code.

This is an advanced workflow because it requires deep knowledge of programming languages (C and Rust), setting up specialized development environments, and understanding how to compile and benchmark software. It is not a simple copy-paste task, as the exact code and setup will vary based on your specific project and computer system.

## What you can use it for
*   **Compare programming language choices**: Use AI to get initial insights into which language might be better for a specific technical task, considering factors like performance, code complexity, or file size.
*   **Prototype code snippets**: Ask AI to generate starting code for specific functions or components, such as a text parsing function for a database.
*   **Benchmark performance**: Get AI to suggest methods or even generate code for testing the speed and efficiency of different software implementations.
*   **Refine technical reports**: Use AI to help structure and write technical documentation or research reports based on your findings and benchmarks.

## Tools you need

## How it actually works
This process involves using an AI as a guide and assistant for a technical development task. The exact steps and code will depend on your specific project and development environment.

1.  **Define your technical problem**: Clearly describe the function or component you want to build and the specific aspects you want to compare (e.g., performance, code size, complexity). For this workflow, the author wanted a `parse_number()` function for SQLite.

2.  **Prompt the AI for initial research**: Ask the AI to compare different approaches or programming languages for your problem. The author's prompt was:

    ```
    I'm thinking about a SQLite custom function 'parse_number(value)' that strips ',', ' ', '£' and '%', handles a leading '-', and returns 'NULL' for anything it can’t parse Explore the difference between building this as a SQLite extension in C v.s. in Rust - I want to compare performance and code complexity and size of the resulting .so (or whatever) file
    ```

    You should get a starting point for your research, including potential libraries or approaches.

3.  **Iterate on code generation and refinement**: Based on the AI's initial suggestions, ask it to generate specific code snippets or functions. The author asked Claude to improve the C implementation:

    ```
    Try writing your own C function for parsing text into a decimal number that catches up to or beats the Rust implementation
    ```

    The AI will provide code that you can then test and refine.

4.  **Implement and benchmark locally**: Take the AI-generated code, set up your development environment (install C compiler, Rust toolchain, SQLite development headers), compile the extensions, and run your own performance tests. This step requires significant technical skill to set up and execute accurately.

5.  **Refine and report**: Use the AI to help structure your findings into a report. The author prompted:

    ```
    Rewrite the prototype as a research report to match the others in simonw/research
    ```

    This helps organize your technical results into a clear, understandable document.

## Words you'll see, explained
*   **SQLite**: A very small, fast, and self-contained database that stores all its data in a single file.
*   **Extension**: An add-on program that adds new features or functions to an existing software, like SQLite.
*   **C**: A powerful, low-level programming language often used for system programming and applications where speed is critical.
*   **Rust**: A modern programming language known for its focus on safety, speed, and handling multiple tasks at once, often seen as an alternative to C++.
*   **`.so` file**: A "shared object" file, which is a compiled library of code that programs can use (similar to a `.dll` file on Windows).
*   **Benchmarking**: The process of testing and comparing the performance (e.g., speed or efficiency) of different programs or code snippets.
*   **`strtod`**: A standard C programming function used to convert a string of text into a double-precision floating-point number.
