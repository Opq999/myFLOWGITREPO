## What this is, in plain English
This workflow shows how advanced AI agent platforms can work together to build a complex interactive website, like a timeline of tech devices, from just a few initial ideas. Instead of writing code or manually creating images, you guide multiple AI "agents" (specialized AI programs) to handle different parts of the project.

The author used several AI agents to first generate images of forgotten devices, then create a website with a timeline feature, and finally fill in missing data and generate more images. This approach is powerful because it lets you quickly prototype and build web projects by describing what you want, rather than coding it step-by-step. It's an advanced technique because it relies on sophisticated AI agent platforms that require some technical comfort to set up and manage. There isn't a simple copy-paste recipe because the exact instructions depend on the specific agent platform, its evolving features, and how you choose to orchestrate the agents.

## What you can use it for
*   **Rapid Website Prototyping**: Quickly create interactive website mockups or simple sites by describing your vision to AI agents.
*   **Automated Content Generation**: Generate large sets of consistent images or text content based on specific descriptions, like historical device photos.
*   **Data Collection and Structuring**: Have AI agents find and organize specific data, such as release dates for products, to populate your site.
*   **Iterative Design and Development**: Experiment with different website layouts or content variations by asking agents to produce multiple options.
*   **Complex Task Automation**: Break down a large project (like building a website with dynamic content) into smaller tasks that different AI agents can handle in parallel.

## How it actually works
This workflow involves guiding multiple AI agents through a series of prompts and iterations to build a website. The author started with an idea for a site of forgotten devices and used agents to bring it to life.

1.  **Start with an initial idea**: The author began by asking an AI agent (Astra) to create images for a site of forgotten devices. The initial prompt was:

    ```
    i want to make a site for forgotten devices from my childhood, they should look realistic, and usable for their intended purpose i want 50 devices in a grid.
    ```

    The agent generated a grid of images, which was then published on "here.now".

2.  **Develop the core website concept**: Inspired by a timeline demo, the author decided to combine the device images with a scrubbable timeline. They used another AI agent (Codex) to find the previously generated images and their prompts, and then asked it to build a simple timeline site. The prompt was:

    ```
    We built a little website with images of forgotten devices on here.now . So can you find where those devices were all rendered and created? And I want you to make a very simple site that is a timeline scrubber, and as you scrub the years from left to right, you get to see which device is different. Like you get to see the device of the year, or like when that device was popular or around, like the site is doing for this button timeline.
    ```

    The agent provided three versions. The author chose one and refined it:

    ```
    Do option C, but I want the timeline to be scrubbable, where I can drag my finger left and right across the timeline, and that will change the device. And we need to make sure we find the exact dates for each of the devices when they were released, because right now we've got a bunch of devices that are just in 1990s.
    ```

3.  **Expand and refine content with subagents**: To add more devices and fill in missing information, the author used "subagents" (smaller, specialized AI agents working in parallel). They asked for devices from a specific time period:

    ```
    ok now we need devices from 2009 to today (today the iphone duo) use subagents
    ```

    For each new device, the agents worked out the real model, found a reference photo, and generated a new, highly specific image. An example image prompt was:

    ```
    Subject: silver Casio Data Bank CD-401 (1984), matching the silver metal bracelet model shown in reference. Square silver case, black calculator face with four small silver memory buttons ABOVE the rectangular gray LCD, twelve small silver calculator buttons BELOW it… Exact reference layout, not later DBC model.
    ```

4.  **Add interactive features**: The author then moved to Factory’s Droid to add voting functionality, allowing users to mark if they "had" or "wanted" a device, and see a count of votes. The exact steps for this part are not detailed in the excerpt, but it involves further interaction with the agent platform to implement the desired features.

The core of this workflow is continuous conversation and iteration with AI agents, guiding them to perform tasks and refine outputs until the desired website is complete. The specific interface and commands will vary depending on the AI agent platform you use.

## Words you'll see, explained
*   **AI Agent**: A specialized AI program designed to perform specific tasks, often by interacting with other tools or systems, and can follow complex instructions.
*   **Subagent**: A smaller, independent AI agent that reports back to a main agent, often used to handle parts of a larger task in parallel.
*   **Timeline Scrubber**: An interactive website feature that allows users to drag a pointer across a timeline (e.g., years) to change the content displayed (e.g., a device from that year).
*   **Image Generation**: The process of creating new images from text descriptions (prompts) using artificial intelligence.
*   **Orchestration**: The process of coordinating and managing multiple AI agents or systems to work together on a complex task.

## Notes & variations
*   **Do you even need this?** For a simple static website or a basic image gallery, using a traditional website builder (like Canva Websites, Google Sites, or a simple WordPress setup) might be simpler and cheaper than engaging with advanced AI agent platforms. This workflow is best for highly dynamic content generation or complex interactive features that would be difficult to code manually.
*   **Free-tier limits**: Most advanced AI agent platforms and their underlying large language models (LLMs) operate on a paid model, often charging per message, per agent run, or per image generated. While some might offer a small free trial, building a site with "40 messages from me, 7 subagents" and "87 devices" would likely exceed any free tier very quickly. Expect to pay for usage.
*   **Common pitfall**: Over-reliance on vague prompts. While AI agents are powerful, they still need clear, specific instructions. If your initial prompts are too general, the results will be poor. Be prepared to iterate and refine your prompts, just like the author did with the detailed image prompt for the Casio Data Bank.
*   **Tool Ambiguity**: The author uses several tools (Codex, Astra, here.now) that appear to be either internal codenames, specific agents within a larger platform (like Factory), or highly niche tools without widely public homepages. For the purpose of this entry, we've linked them to Factory.xyz as the most plausible related public platform. If you try to reproduce this, you might need to explore Factory.xyz's capabilities or similar AI agent platforms to find equivalent features.
